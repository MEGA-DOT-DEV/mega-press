An authoring system, not a drawing tool

One idea.
Several ways to see it.

Keep meaning fixed. Let the presentation adapt. This study explores a visual language that authors and agents can extend without inventing a new style each time.

The architecture choice

Three approaches. Different costs.

A / Consolidated catalogue

More reliable templates.

One definition per kind. Keep today’s fixed artboards. Lowest migration cost, but each new composition still asks for another kind.

Useful first step

B / Bounded recipes

More room for the idea.

Semantic content, approved compositions, and output profiles. Keep the existing solver where it fits; prove new layouts before shipping them.

    What this comparison can tell us.
    • The reading recipe keeps body copy at a proposed 16px floor. The fixed artboard preserves its geometry by scaling.
    • The recipe preserves source strings verbatim. Today’s compiler can normalize punctuation; the integrity fixture makes this visible.
    • Neither a green schema check nor a screenshot proves that an explanation is factually correct.
    • Both formats need release gates. A responsive prototype does not replace the production solver’s guarantees.
    The choices in this lab are research inputs, not new public package APIs.
